Configuração da sincronização

Esta versão usa uma base de dados online para que a mesma conta veja os mesmos dados no PC e no telemóvel. Antes de publicar, é preciso ligar o site ao teu projeto Supabase.

1. Cria um projeto no Supabase. 2. Cria uma tabela chamada multiples com as colunas indicadas abaixo. 3. Ativa RLS e usa as políticas indicadas. 4. Substitui no código COLOCA_AQUI_O_PROJECT_URL e COLOCA_AQUI_A_ANON_KEY.

create table public.multiples ( id bigint generated by default as identity primary key, user_id uuid not null references auth.users(id) on delete cascade, created_at timestamptz default now(), date date, name text, result text not null, notes text, selections jsonb not null default '[]'::jsonb ); alter table public.multiples enable row level security; create policy "Users can read own multiples" on public.multiples for select using (auth.uid() = user_id); create policy "Users can insert own multiples" on public.multiples for insert with check (auth.uid() = user_id); create policy "Users can delete own multiples" on public.multiples for delete using (auth.uid() = user_id);

Importante: no coloques uma chave secreta/service-role no site. O site deve usar apenas a chave pública/anon do projeto, protegida pelas políticas RLS.

Os dados pertencem à conta autenticada e não são guardados apenas no navegador.
